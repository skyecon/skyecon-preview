Transcript Studio Support

Release, privacy, and security support for Transcript Studio on Windows.

Contact

Use the Skyecon contact page and identify the message as a Transcript Studio support request.

Telephone: +1 (778) 562-6728

Before requesting support

  1. Record the Transcript Studio version shown in About.
  2. Record the Windows edition and version.
  3. Describe the action that failed and the exact on-screen error.
  4. State whether the recording is locally available or a cloud placeholder.
  5. Do not send a protected recording, transcript, workspace, credential, or model file unless Skyecon expressly requests a specific non-sensitive diagnostic and you are authorized to provide it.

Security reports

Identify the message as a Transcript Studio security report. Include the affected version, Windows version/architecture, concise reproduction steps, expected and observed behaviour, and whether the issue could expose, alter, delete, or misattribute source-linked material. Do not include private recordings, transcripts, credentials, or exploit payloads containing personal information in the initial report.

Microsoft Store purchases

Microsoft Store manages the trial, checkout, payment, receipt, entitlement, reinstall, and Store updates. There is no Skyecon licence key or separate billing account. For a missing entitlement, confirm that Windows and Microsoft Store are signed into the Microsoft account that acquired Transcript Studio.

Important limitation

Transcript Studio produces a machine-generated working transcript and navigation aid—not a certified or official transcript. Verify important passages and speaker labels against the original recording.

Privacy

Read the Transcript Studio Privacy Policy for local storage, network activity, capability-pack downloads, retention, and security information.
