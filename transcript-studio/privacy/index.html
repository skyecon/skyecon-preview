Privacy Policy

How the Transcript Studio desktop application, published by Skyecon, handles information.

Privacy summary

  • Recordings, transcripts, speaker labels, corrections, searches, summaries, and transcript questions are processed locally during ordinary use.
  • No account, API key, cloud inference server, or external AI runtime is required for the included workflow.
  • Transcript Studio does not intentionally upload recordings or transcripts to Skyecon or capability-pack providers.
  • The current application contains no Skyecon advertising, behavioural analytics, or telemetry.
  • First-use capability-pack downloads require an explicit disclosure and user consent.
  • Microsoft Store manages trial status, checkout, payment, entitlement, installation, and updates; recordings and transcripts are not included in Store licence requests.

Information stored locally

Transcript Studio normally stores its workspace under %LOCALAPPDATA%\LocalTranscriptStudio. Local data can include immutable source snapshots and hashes, normalized analysis derivatives, timestamps, speaker regions, raw machine transcripts, reviewed layers, correction ledgers, checkpoints, search indexes, local summaries and answers, exports, receipts, model files, manifests, and settings.

The application does not currently encrypt the workspace itself. Protection depends on the Windows account, device security, filesystem permissions, and device or volume encryption. Uninstalling the application does not automatically delete the workspace or exports.

Network activity

Transcript Studio connects to Microsoft Store for trial and purchased licence status, Microsoft checkout, installation, and updates. Microsoft may process Microsoft-account, device, transaction, entitlement, diagnostic, and network information under its own terms and privacy statement. Store requests do not include recordings or transcript content.

After explicit first-use approval, Transcript Studio may download pinned and integrity-verified capability files from huggingface.co and GitHub release infrastructure. Those services can receive ordinary connection information such as public IP address, request time, requested file, TLS/network information, and user-agent information. Transcript Studio disables Hugging Face telemetry and implicit-token use where supported. Recording or transcript content is not included in capability-pack download requests.

Microsoft Store, Windows, security software, network administrators, and operating-system services may separately collect information under their own policies.

Information Skyecon receives

The desktop application does not currently send Skyecon recordings, transcripts, usage analytics, or crash reports. Skyecon receives information only when a user deliberately contacts support, submits a diagnostic, uses a Skyecon website form, or completes a purchase through a distribution platform. That information is used to respond, diagnose problems, maintain security, and meet legal obligations.

Do not send protected recordings or transcripts to support unless Skyecon expressly requests a specific non-sensitive diagnostic and you are authorized to provide it.

Retention and deletion

Users control local workspace retention. Removing an original file does not remove the immutable workspace snapshot. Uninstalling Transcript Studio does not automatically delete workspace data. Users must delete local projects, exports, backups, and workspace files according to their authority and retention obligations.

The general release does not enforce court- or jurisdiction-specific retention and destruction rules. Local processing alone does not establish authority to copy, convert, retain, or export a protected recording.

Children

Transcript Studio is a professional productivity tool and is not directed to children. It is not intended to collect children’s personal information through a Skyecon-operated online service.

Security

Transcript Studio uses integrity manifests, pinned revisions, source hashes, transactional exports, and fail-closed checks to reduce tampering and accidental corruption. No system is perfectly secure. Keep Windows updated, restrict device access, use device encryption where appropriate, and maintain authorized backups.

Changes and contact

Material policy changes will update the effective date and product documentation. Privacy questions can be submitted through Transcript Studio Support or the Skyecon contact page.
